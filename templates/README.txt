Сюда положи PNG-картинки кнопок/полей Linken Sphere 2, по которым скрипт будет искать
их положение на экране. Каждое изображение — небольшой кроп (только сама кнопка/иконка
+ чуть-чуть фона), сохранённый под точным именем:

  three_dots.png              — кнопка "три точки" в главном окне
  warm_up_menu.png            — пункт "Warm up" в выпадающем меню
  viewing_depth_field.png     — поле ввода viewing depth (со значением 1 по умолчанию)
  time_per_url_field.png      — поле ввода time per url (со значением 3 по умолчанию)
  use_most_popular_checkbox.png — галочка "use most popular" слева снизу (в состоянии ВКЛ)
  browse_file_button.png      — кнопка "Browse file"
  start_button.png            — кнопка "START"

Как вырезать:
  1. Открой Linken Sphere 2, доведи до нужного экрана.
  2. Нажми Win+Shift+S (Snipping Tool), выдели только саму кнопку.
  3. Сохрани под точным именем из списка выше в эту папку.

Чем точнее кроп — тем стабильнее работает скрипт. Не включай в кадр меняющийся
текст (счётчики, время) — берите только статичную часть.
