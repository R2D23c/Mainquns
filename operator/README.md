# operator/ — инструменты для парка (запускаются на ноутбуке оператора)

Живут **отдельно от пайплайна VPS**: ничего из этой папки на машины не
качается и не влияет на прогрев. Это утилиты для тебя, на твоём Windows-ноуте.

Два независимых пути «одна кнопка → все VPS открыты». Нужен **один**:
- **mRemoteNG** (GUI, рекомендуется для парка) — массовый импорт через
  `mremoteng-import.ps1`, ниже.
- **fleet.ps1** — без стороннего софта (нативные `.rdp` + `cmdkey`),
  запасной вариант. См. раздел в конце.

---

## mremoteng-import.ps1 — массовый импорт парка в mRemoteNG (до 30+ VPS)

Готовит CSV со всеми VPS для `File -> Import -> Import from CSV`, чтобы не
вбивать каждую машину руками. Схему (разделитель, колонки, значение
Resolution) берёт из ТВОЕГО экспорта — работает на любой версии mRemoteNG
без угадывания формата.

### Один раз — эталон

1. В mRemoteNG настрой **одно** подключение как надо, в т.ч.
   **Config -> Display -> Resolution = 2560x1440**. Проверь, что коннектится.
2. Выдели его -> **File -> Export** -> сохрани `template.csv` (тип
   «mRemoteNG CSV»).

### Каждая партия

```powershell
cd путь\к\repo\operator
Copy-Item hosts.csv.example hosts.csv     # если ещё нет
notepad hosts.csv                         # впиши парк: name,ip,user,password
.\mremoteng-import.ps1 -Template template.csv
```

Затем в mRemoteNG: **File -> Import -> Import from CSV** -> выбери
`mremoteng-import.csv`. Все VPS появятся разом, с паролями и резолюцией
1440p (унаследованы из эталона). Правый клик по папке -> **Connect** —
открыть весь парк.

Параметры: `-HostsFile D:\batch2.csv`, `-Out D:\import2.csv`,
`-Resolution Res2560x1440` (принудительно, если эталон был не в 1440p).

### Безопасность

`hosts.csv` и `mremoteng-import.csv` — **gitignored** (как `credentials.ini`).
Пароли парка = секрет, живут только на ноуте. После импорта сгенерённый
`mremoteng-import.csv` можно удалить — пароли уже в профиле mRemoteNG.

## fleet.ps1 (альтернатива без mRemoteNG)

## fleet.ps1 — one-click RDP ко всему парку

Открывает все VPS парка одной командой, с уже введёнными паролями и
зафиксированной резолюцией 2560×1440. Только PowerShell + встроенные
`mstsc`/`cmdkey` — стороннего софта ставить не нужно.

### Быстрый старт

```powershell
cd путь\к\repo\operator
Copy-Item hosts.csv.example hosts.csv     # один раз
notepad hosts.csv                         # впиши свои IP и пароли
.\fleet.ps1                               # открыть весь парк разом
```

`.\fleet.ps1` (действие `all`) сгенерит `.rdp`-файлы и откроет все окна.
mstsc не спросит пароль — он закэширован через `cmdkey`.

### hosts.csv

```csv
name,ip,user,password
vps-1,203.0.113.10,Administrator,ChangeMe1
vps-2,203.0.113.11,Administrator,ChangeMe2
```

- `name` — необязательно (по умолчанию IP с заменой точек на дефисы).
- `user` — необязательно (по умолчанию `Administrator`).
- `password` — пароль Windows-админа VPS.

**hosts.csv в `.gitignore`** — как `credentials.ini`, никогда не коммить.
Пароли парка = секрет, живут только на твоём ноуте.

### Команды

| Команда | Что делает |
|---|---|
| `.\fleet.ps1` или `.\fleet.ps1 all` | сгенерить `.rdp` + открыть все |
| `.\fleet.ps1 gen` | только сгенерить `.rdp` (без открытия) |
| `.\fleet.ps1 connect` | только открыть все (`.rdp` уже сгенерены) |
| `.\fleet.ps1 clean` | убрать закэшированные пароли из Credential Manager |

Другой файл списка: `.\fleet.ps1 -HostsFile D:\batch2.csv`.

### После работы — дисциплина из CLAUDE.md

- **Закрывай окно (disconnect)**, НЕ `Sign out` / `Log off`. Logoff убивает
  LS + watchdog на VPS → ложные ⚠️-пуши, прогрев прерывается.
- Резолюция уже 1440p в `.rdp` — на 1080p-мониторе сессия откроется в окне
  со скроллом (VPS-сторона честно рендерит 1440p, templates матчатся).
- Когда парк списан: `.\fleet.ps1 clean` — стереть пароли парка с ноута.

### Что это НЕ делает (и почему)

Автоматически «напечатать setup-команду во все окна разом» — нет: на голой
VPS, доступной только по RDP, командного канала не существует (RDP — это
протокол картинки), а надёжного broadcast-набора в бесплатных RDP-тулах нет.
Инструмент убирает главную боль — открыть 5 окон и залогиниться в каждое;
setup-команду вставляешь в открытые окна сам. Автоматизация самой команды
(recovery, сбор cookies) — отдельный шаг через WinRM, если решишь его делать.
