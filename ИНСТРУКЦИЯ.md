# Инструкция по запуску (для новичков)

Прогрев Linken Sphere 2 на свежей Windows-машине. Всё ставится автоматически
одной командой. От тебя нужно только вписать логин/пароль один раз.

Подходит для: Windows 10 / 11 / Server 2019+ (32 и 64 бита).

---

## Что тебе понадобится

1. Доступ к машине (RDP / консоль).
2. Email и пароль от аккаунта Linken Sphere 2.
3. ~10 минут времени на установку (дальше всё само).

Ничего предварительно ставить НЕ надо — ни Git, ни Python, ни Linken Sphere.
Команда поставит всё сама.

---

## Шаг 1. Открой PowerShell от имени администратора

1. Нажми правой кнопкой по меню **Пуск** (или клавиши `Win + X`).
2. Выбери **Windows PowerShell (администратор)** или **Терминал (администратор)**.
3. Если спросит «Разрешить внести изменения?» — нажми **Да**.

> Важно: именно **от администратора**. Без прав админа установка прервётся
> с сообщением `[ERROR] Admin rights required`.

---

## Шаг 2. Вставь и запусти ОДНУ команду

Скопируй строку целиком, вставь в окно PowerShell (правая кнопка мыши =
вставка) и нажми **Enter**:

```powershell
iwr -useb https://raw.githubusercontent.com/r2d23c/mainquns/main/setup.ps1 | iex
```

Дальше всё идёт само (5–10 минут):

- ставится Git;
- ставится Python 3.12;
- скачивается проект в папку `C:\warmup`;
- ставятся зависимости Python;
- скачивается и ставится Linken Sphere 2 (~150 МБ).

Просто жди. Окна будут что-то писать — это нормально.

---

## Шаг 3. Впиши логин и пароль (один раз)

В какой-то момент **сам откроется Блокнот** с файлом `credentials.ini`:

```ini
[account]
email = your@email.com
password = yourpassword
```

1. Замени `your@email.com` на свой **email от Linken Sphere 2**.
2. Замени `yourpassword` на свой **пароль**.
3. Сохрани: **Ctrl + S**.
4. Закрой Блокнот.
5. Вернись в окно PowerShell и **нажми любую клавишу**, чтобы продолжить.

> Пример как должно выглядеть:
> ```ini
> [account]
> email = mylogin@hotmail.com
> password = MyPass123!
> ```

Файл `credentials.ini` хранится только на этой машине и никуда не отправляется.

---

## Шаг 4. Готово — можешь уходить

После этого скрипт сам зарегистрирует задачу в планировщике Windows и напишет:

```
[setup] DONE. You can close windows and walk away.
        First trigger fires in 15 seconds.
```

**Всё. Закрывай окна и уходи.** Дальше машина работает сама:

- Через 15 секунд запустится первый прогон. Первый раз он сделает вход,
  активирует API-порт и импортирует сессию (тут возможны всплывающие окна
  Linken Sphere и фаервола — скрипт закроет их сам).
- Дальше каждые ~45 минут запускается прогрев по ~100 ссылок.
- Когда суммарно прогреется **300–500 ссылок** (число выбирается случайно),
  задача сама выключится. Работа завершена.

---

## Шаг 5. (Необязательно) Уведомления на телефон

Чтобы видеть прогресс и завершение, подпишись на уведомления — на выбор:

### Вариант A — приложение ntfy
1. Установи приложение **ntfy** (Android / iOS).
2. Добавь подписку на топик:
   ```
   warmup-r2d2-7m9k4n2p8q5xFx168xx1QQE
   ```

### Вариант B — Telegram
1. Открой бота **@ntfytgbot** в Telegram, нажми `/start`.
2. Подпишись на тот же топик:
   ```
   warmup-r2d2-7m9k4n2p8q5xFx168xx1QQE
   ```

Какие сообщения будут приходить:

| Сообщение | Что значит |
|-----------|------------|
| `warmup OK` ✅ | UI install прошёл, машина начала первый прогрев в фоне |
| `warmup cycle` ⚙️ | один цикл прогрева отработал, виден прогресс (например `progress: 200/450`) |
| `warmup all done` 🎉 | цель достигнута, машина закончила работу |
| `cycle paused` ⏳ | один цикл столкнулся с lock'ом, retry на следующем тике (тихое) |
| `warmup failed` ⚠️ | что-то упало (приходит со звуком) — загляни в машину |

В каждом сообщении первой строкой идёт `session:` (имя сессии `CL-XXXXXXXX`),
второй — `machine:`. По ним легко понять, с какой машины пришло.

---

## Если что-то пошло не так

| Проблема | Что делать |
|----------|-----------|
| `Admin rights required` | Закрой окно, открой PowerShell **от администратора** (Шаг 1), повтори. |
| `'iwr' is not recognized` | Ты в обычном `cmd`, а нужен **PowerShell**. Открой именно PowerShell. |
| Установка зависла на Python/Git | Закрой окно, открой PowerShell-админ заново и снова вставь команду из Шага 2 — она продолжит с места установки. |
| Хочу начать заново с чистого листа | В папке `C:\warmup` запусти `restart.bat`, затем снова `schedule_hourly.bat`. |
